CAREER COMPASS — NEXT STEP: JAVA BACKEND ROADMAP

Files:
- index.html / style.css / script.js: homepage
- roadmap.html / roadmap.css / roadmap.js: Java Backend Developer roadmap

Run it:
1. Extract the ZIP.
2. Keep all six files in the same folder.
3. Open the folder in VS Code.
4. Right-click index.html and choose Open with Live Server (recommended), or open index.html in a browser.
5. Click “View roadmap” under Backend Developer.

Features:
- Six learning stages and 18 checkable topics
- Progress percentage updates automatically
- Progress saves in this browser using localStorage
- Reset progress button
- Links to official Java, Git, MySQL, and Spring learning resources

Note:
This is a front-end prototype. Progress is saved only in the current browser/device, not in a user account or MySQL. Login, multi-user progress, and Spring Boot API integration are future steps.
